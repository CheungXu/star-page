# 首屏输入区高度调整

## 背景

首页输入卡片里，上传文档条比书写区更高，看起来上传是主入口、输入是附注。希望改成输入框为主、上传为副，同时上传仍然醒目，两者高度不要差太多。

## 方案

同一张卡片内微调高度，不改文案和操作：

- 上传条略收矮，保留浅蓝底、虚线框、图标和「选择文件」。
- 输入框略抬高，空态只比上传条高出大约 10px。
- 字变多时输入框仍会继续增高。
- 曾把输入框放到约 82px，比上传条高出约 18px，看起来空白太多。收到约 74px 对 64px 后确认上线。有底色和按钮的上传条，同样高度比空白输入框更显眼，所以两者只差大约 8px。

## 进度

- 高度差收过一次：空态输入框约 74px，上传条约 64px。
- 线上模型目录已是 9 个。模型浮层加宽到 300px，打开时把下方场景芯片下移到浮层之下，长名字不再被「登录可用」挤掉。
- 已构建并重启前端，线上首页已换成这一版。测试端口 3001 已关闭。
