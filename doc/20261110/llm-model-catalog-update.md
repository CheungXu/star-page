## 取舍

- DeepSeek Flash 的目录 key 没改，已经勾选的人会自动用上 1017。百炼上无日期的 `deepseek-v4.1-flash` 和 `deepseek-v4.1-flash-1017` 同时在售、价格相同，槽位改挂带日期的快照。
- DeepSeek V4 Pro 继续用裸名 `deepseek-v4-pro`（12 / 24 / 1）。百炼上另有 `deepseek-v4-pro-0813`，高峰价是 9 / 27 / 0.9，两个 ID 不是同一个在售商品，这次没有把槽位改到日期快照。
- Kimi 的版本写在 key 里，所以 key 从 `kimi-k3` 改成 `kimi-k3.1-pro`。旧 key 的 1.5 倍加价先留着。浏览器里勾过 K3 的，需要重新选一次。K3.1 Pro 同样不接受 `temperature`，报错文案仍写成 kimi-k3。加价倍率仍是 1.5。
- GLM-5.3 Flash 在百炼的 ID 是 `ZHIPU/GLM-5.3-Flash`。给业务空间授了推理权限之后，调用仍返回产品未开通；裸名 `glm-5.3-flash` 是拒绝访问。没有把未开通的 ID 写进目录。方舟上的 `glm-5-3-flash-260828` 可以正常回复，单价与百炼标价一致，所以这档走方舟、用现有的方舟密钥。加价按便宜档 1.2 倍，不跟 GLM-5.3 的 1.5 倍。
- 方舟价格接口不返回单价。GLM Flash 的单价来自方舟公开价目，以后调价需要再对一次。
