## 取舍

- 通义没有 3.8 Plus，原来的 Plus 槽改挂 3.8 Flash。槽位 key 没改，已勾选的用户会自动用上新模型。
- 豆包没有 2.1 Code，原来的 Code 槽改挂 2.1 Turbo。Turbo 单价约为 Pro 的一半。槽位 key 同样保留。
- 豆包 2.1 一开始返回未开通。开通后 Pro、Turbo、Lite 都能通。Pro 用较新的 `260915`，Turbo 只有 `260628`。
- Kimi 的 K2.8 调不通（裸名不存在，带厂名前缀未开通），能用的最新版是 K3。输出单价从 27 涨到 100，加价倍率仍是 1.5。
- DeepSeek 没有 V4.1 Pro。Flash 官方分高峰和低峰，低峰是高峰的一半。现有计费不分时段，按高峰入账，避免高峰少计成本。
- DeepSeek V4 Pro 的模型名没变，但目录里的旧价（输入 3 / 输出 6）已经和现价不符，已改成 12 / 24。
- 版本写在 key 里的模型（Flash、GLM、Kimi）换了 key。旧 key 的加价倍率先留着，避免更新瞬间还没结算的生成找不到倍率。浏览器里勾过这些旧名字的，需要重新选一次。

## 生效与验证

改的是模型目录和计费配置，后端启动时读入。重启后端后，模型列表 8 个都可用。每个模型的最小对话都返回成功；思考模型在输出额度很小时可能只有思考、没有正文，把额度加大后能正常回复。
