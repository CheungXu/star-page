# 博主主页专项制作指南

做一个能放进小红书或公众号简介的个人主页。90% 的访问来自手机，第一屏就要让人想关注。

## 第一屏

- 圆形头像（没有图片时用昵称首字做渐变头像）、昵称、一句话定位、2-3 个身份标签。
- 紧接着一排平台入口，手指能直接点到。
- 背景用柔和的渐变或纹理，不要纯白，也不要大块深色压住头像。

## 信息架构

1. 头图区：头像、昵称、定位、标签。
2. 平台入口：小红书、公众号、B 站、抖音等，每项一张可点的卡片，带平台色小图标（用 CSS 或 SVG 画，不用外链图片）。只放需求里给出的平台。
3. 代表作品或课程：2-6 张卡片，标题加一句说明，可以带「热门」「新」角标。
4. 微信：单独一块，尺寸明显大于其他卡片。有二维码图片地址时必须用 `<img>` 展示，并写「长按识别二维码加微信」。没有二维码时写「私信获取微信」。

## 视觉

- Bento 卡片网格：大小不一的圆角卡片（16-24px 圆角），间距一致，像一组精致的 App 小组件。
- 移动端优先：最大宽度 480px 居中；桌面端两侧留白，不要拉成宽屏文档。
- 一种主色贯穿按钮和重点卡片，配一种低饱和辅助色。
- 卡片有轻微阴影和按下反馈。

## 易错点

- 没给出的平台不要编造粉丝数、获赞数或链接。
- 二维码是转化重点，不要藏到页脚小字里。
- 外链用 `<a target="_blank">`，不要用会提交的表单。
- 不要在顶部放编辑说明或「替换成你的信息」之类的提示。
