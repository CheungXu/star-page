# 活动邀请函专项制作指南

做一封在微信里打开的竖屏邀请函。它不是信息站，也不是海报墙。

## 信息架构（自上而下，一屏接一屏）

1. 封面：活动名、一句邀请语。有主视觉图片地址时用 `<img>` 铺满封面。
2. 时间与地点：日期、时刻、场地名称。可以写地址文字，不要嵌地图 iframe。
3. 议程：按时间排列的短清单。
4. 着装或须知：一两句。
5. 报名：一个主按钮链到需求里的外部报名地址；有二维码图片时展示二维码。不要做会提交到服务器的表单，不要写“提交报名”。
6. 倒计时只在用户给了完整日期、且你不能确定它已经过去时才写。没有年份就不要编一个过去的年份，也不要写「活动已结束」或「已圆满举行」。不确定就只展示用户给出的时间地点。

## 视觉

- 封面就是第一屏：活动名要大、有仪式感，日期和城市紧跟在下面，一眼能看全。手机竖屏里不要只露出一块空背景。
- 没有主视觉图片时，用 CSS 渐变、几何线条或 SVG 纹样做封面，不要留大片纯色。
- 竖屏比例，最大宽度约 480px 居中，两侧留白。
- 字体有仪式感，配色统一。婚礼偏暖，沙龙可以更冷静。
- 动效只做封面淡入。打印时去掉倒计时动画。

## 易错点

- 不要编造未给出的嘉宾名单和票价。
- 没有报名链接和二维码时，只写“名额有限，联系主办方”，不要伪造链接。
