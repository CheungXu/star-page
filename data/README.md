# data

数据目录，存放相关数据。

- `growth/xhs/`：小红书公开热词与笔记搜索结果。热词榜可重复拉取；笔记搜索按关键词断点续跑，只保留已成功的记录。
- `文案/202610/`：增长投放与通告博主物料。包含共用规范 `00-共用说明.md` 以及按不同垂直人设（春招应届、设计师作品集、跳槽对比、编导作品、零基础对照）独立归档的文案与封面。
  - `发包/`：交给推广人的五个图文压缩包。每个包只有封面、这篇要用的真实配图和 `00-发布说明.txt`，没有试稿、改稿记录和讲解视频。`*.zip` 不入库，需要时运行 `python3 script/pack_promo_kits.py`。
  - `00-界面截图/`：线上真实界面截图（首页、场景页、四个案例页、工作区生成全过程），由 `script/promo-capture/` 生成。
  - `00-界面截图/小红书配图/`：拼好的 3:4 真实截图配图，发笔记时放在 AI 封面后面。
- `视频/202610/星页一分钟讲解/`：一分钟竖屏讲解视频的 hyperframes 工程。台词在 `src/script.json`，画面模板在 `src/index.html.tpl`，成片在 `renders/`。生成方法见 `script/README.md`。
