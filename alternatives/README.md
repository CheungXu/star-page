# 备选方案库

选型时没被选中、但值得留作后续 AB 测试或回溯的方案，按项目归档在这里。每个项目一个子目录，`README.md` 写清楚：

1. **背景与线上方案**：要解决什么问题，最终上线的是哪一版、为什么。
2. **备选方案**：每个方案的做法、优缺点、截图，以及当时为什么没选。
3. **代码在哪**：主线里是否还保留（怎么切换），完整演示版本在哪个 git 标签 / 分支，关键文件。
4. **怎么复现**：本地起多端口演示、或在线上切换的命令。
5. **AB 测试建议**：要比较的指标、埋点事件、分流方式。

与其它目录的分工：`doc/` 记录项目过程（按日期），`wiki/` 沉淀可跨项目复用的经验；这里只回答「当时还有哪些方案、现在怎么把它们拿出来比」。

## 收录约定

- 目录名用英文短横线，例如 `preview-toolbar/`；截图放 `images/{日期}/{项目}/`，这里引用路径即可。
- 落选方案的完整代码打 git 标签存档（命名 `alt/{项目}-v{n}`），主线只保留确有 AB 计划的方案，避免长期维护负担。
- 方案上线、被淘汰或做完 AB 测试后，在对应项目的「状态」里补一行结论和日期。
